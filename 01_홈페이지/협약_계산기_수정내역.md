## 유지한 기능과 변경한 계산

기존 상담계산기의 건물주 현금흐름 비교, 출자금 배분, 월별 그래프, 은행 창업대출·대환·계좌 규모와 마진 가정을 가져왔습니다. 상권 전체로 단순 확대하는 숫자와 검증되지 않은 구역별 평균 입력은 복원하지 않았습니다.

비교안과 참여안 모두 입점 2개월 뒤 같은 유지율을 적용합니다. 기본은 양쪽 연 입점률 25%이며 자동 입점 반응 계수는 사용하지 않습니다. 참여 입점률은 상세 설정에서 직접 바꿀 수 있습니다.

은행은 4년 말 잔액에 따른 연간 수익과 다년 우대 비용을 비교하던 방식에서 월별 잔액에 따른 48개월 누적 이자마진으로 변경했습니다. 기존 건물주 거래는 별도이며, 미참여 창업대출 거래분은 추가 수익에서 제외합니다. 대출·예금 잔액은 수익에 더하지 않고 우대 비용은 한 번만 차감합니다.

## 남은 가정

- 입점률·유지율·창업대출 거래 비율·대환 비율은 실측이 아닙니다.
- 은행 마진 2.49%, 가게당 대출 5,000만원, 계좌 잔액 1,500만원은 기존 계산기에서 가져온 검토용 입력입니다.
- 은행 결과는 신용손실·보증료·운영비 차감 전입니다. 조달비용은 입력 마진에 포함된 것으로 가정합니다. 확인된 순이익이 아닙니다.
- 대환은 시작 시 실행, 창업대출은 점포가 영업하는 동안 일정 잔액 유지·퇴거 시 잔액 소멸, 공동기금은 미집행으로 가정합니다.
- 금리 우대는 미승인 제안 조건으로 상담 시작일부터 건물 대출 전체에 적용합니다.
- 재임대·세금·원금상환·공동기금의 입점 증가 효과는 계산하지 않습니다.

## 2026-11-04 · 1차 대상과 협약 연계 은행 상품

### 상생협약(agreement.html)
- 새 섹션 **1차 대상**: 협약 공고일 기준 6개월 이상 비어 있던 충장로 1~3가 점포. 기준일을 고정해 공고 이후 일부러 비운 점포는 제외. 확인 방법(상가정보 대조·임대차 종료일·관리비·공과금 증빙·상인회 확인)과 대상 규모(지도 기준 1~3가 빈 자리 83곳 중 1년 이상 61곳) 표시.
- 구조 설명의 "처음 빈 점포"를 "1차 대상 점포 / 6개월 이상 비어 있던 점포"로 변경.
- 새 섹션 **협약 연계 은행 상품 · 제안**: "충장로 상생협약 건물주 대출 우대(가칭)" 상품 카드(대상·우대 0.3%p 24개월·적용 대출·함께 제공·시범 10개 건물 상한)와 은행이 얻는 것 5가지(대환 유치, 담보 위험 감소, 기존 고객 유지, 새 가게 고객, 지역재투자 실적), 은행 부담(건물당 2년 약 450만원).
- 기존 접힌 문단 "은행은 왜 참여하나요?"는 새 섹션으로 대체해 삭제.
- 역할 카드의 은행 설명 수정, "우대를 넣어 계산해 보기" 버튼 추가(계산기에서 우대가 켜진 상태로 열림).

- 주소에 `bank=1`이 있으면 금리 우대를 켠 상태로 시작.

## 2026-11-04 · 데이터 분석 페이지 제외, 상생협약 재구성

## 2026-11-18 · v5 자생 구조 · 지역상권 퍼스트 + 지역은행

이전 버전 보존: `03_이전버전_기록/홈페이지_20261117_상생협약v4/`

### 바뀐 구조 (6가지 수정 요청 반영)
1. **출자 주체·비율**: 세입자는 계약 월세 100%를 건물주에게 냄. 월세를 모두 받은 건물주가 **건물 등급별 차등 비율(5~15%)** 을 **상인회 기금**에 출자. 첫 2개월 세입자 환급 삭제 → 출자금 전액 기금 적립, 입점 지원은 기금 예산 항목으로 이동.
   - 출자율 = 기본 10% + 입지(대로변·1층 +5 / 평균 0 / 이면·상층 −3) + 공실 기간(6개월~1년 0 / 1년 이상 −2). 제안값.
2. **은행 주도 기금 + AI 예산**: 지역은행이 상인회 기금 계좌를 설정·관리(자동이체·회계 공개·데이터). AI 예산 에이전트가 매달/분기 예산안 작성 → 상인회 승인 → 은행 집행. 새 페이지 `fund.html`.
3. **금리 유지**: "0.3%p 우대"를 핵심에서 빼고, 계약 월세 유지 → 수익환원 건물값·LTV 유지 → **그만큼 금리 유지**로 변경. 계산기에 월세 인하안(기본 20%)과 비교, LTV 1%p당 가산금리 0.03%p·환원율 6.5% 가정. 추가 인하는 선택 조건으로 남김.
4. **키워드 '자생'**: 보조금 없이 도는 구조 강조. 보조금은 매칭(일회성 항목에만 배정, 운영비 제외). 일회성 보조금 사업 vs 상생기금 비교표. 지역은행의 지역 금융 역할 유지.
5. **세일즈**: 상인회 설명회 → 건물주 진단 상담 → 주거래 전환·대환 → 임차인 금융 → 분기 리포트.
6. **타겟**: 자금력 있는 건물주(대환·추후 대출 데이터) → 상권 데이터로 임차인 대출을 안정적으로.
