# 청충어람 · 충장로 상생기금 프로젝트 개요

> **지역상권 살리기(1순위) + 지역은행 살리기(2순위)**
> 키워드 **자생**: 한 번 쓰고 끝나는 보조금이 아니라, 상권 안의 월세로 스스로 돌아가는 상권

---

## 1. 한 줄 요약
광주 충장로의 공실을 데이터로 분석했습니다. 그 근거로 **월세는 그대로 두고, 건물주가 받은 월세의 일부를 지역은행이 관리하는 상생기금에 모아 빈 점포를 채우는 상생협약**을 제안합니다.

## 2. 목적과 목표

| 구분 | 내용 |
|---|---|
| 목표 1순위 · 지역상권 살리기 | 충장로 1~3가의 빈 점포를 채우고, 보조금이 끝나도 상권 안의 월세로 운영되는 기금을 만든다 |
| 목표 2순위 · 지역은행 살리기 | 기금 관리·고객·상권 데이터를 통해, 역할이 줄어드는 지역은행이 지역 금융의 역할을 이어간다 |
| 주요 사용자 · 참여 대상 | 충장로 1~3가에서 6개월 이상 빈 점포를 가진 건물주. 협약 참여 여부를 결정하는 사람 |
| 보조 사용자 | 그 빈 점포에 들어오는 새 세입자, 특히 원도심에서 첫 가게를 여는 **청년 창업자** |
| 지역은행의 영업 대상 | **자금력 있는 건물주**부터 만난다(대환·추후 대출을 위한 데이터 확보). 이어서 그 건물에 들어오는 새 세입자에게 상권 데이터를 근거로 안정적인 대출을 한다 |
| 수혜 | 새 세입자·청년 창업자(입점 지원·홍보·창업대출 상담), 상인회(자체 예산과 결정권), 건물주(월세·건물값·금리 유지), 지역은행(고객·데이터·지역재투자 실적) |

## 3. 왜 필요한가 (문제)
- **공실이 높습니다.** 충장로(금남로/충장로) 중대형 상가 공실률은 26.5%로, 광주 상권 중앙값 12.3%의 약 2배입니다(R-ONE 2026Q2).
- **기다려도 잘 채워지지 않습니다.** 2025.06에 비어 있던 빈 점포 74곳 중 1년 안에 다시 채워진 곳은 13곳(약 18%)입니다(등록정보 기반 추정).
- **월세 인하 협약은 참여가 적었습니다.** 2025년 3월 협약에는 88곳 중 25곳(약 28%)만 참여했습니다.
- **보조금은 한 번 쓰고 끝납니다.** 공모 사업은 예산이 끝나면 운영비도 끊깁니다.
- **빈 점포는 청년이 일하고 창업할 자리입니다.** 원도심에서 첫 가게를 여는 청년 창업자는 초기 비용 부담이 크고 대출 이력이 짧습니다. 건물주가 협약에 참여해야 그 자리에 입점 지원과 상권 데이터 기반 대출 상담이 함께 열립니다.

## 4. 데이터 분석 결과 (이 프로젝트의 근거)
자료는 한국부동산원 R-ONE 상업용부동산 임대동향(전국 359개 상권, 2013Q1~2026Q2)입니다.

| 발견 | 수치 | 의미 |
|---|---|---|
| 공실이 늘어도 임대료는 잘 안 내려간다 | 1년 새 공실률이 3%p 이상 오른 1,707건 중 67%는 임대가격지수가 1%도 내려가지 않음 | 월세를 내리라는 압력이 잘 통하지 않음 |
| 임대료가 건물값을 움직인다 | 임대가격지수 1% 상승 → 1년 자본수익률 +0.51%p. 공실 변화는 건물값에 뚜렷한 영향 없음 | 건물주는 월세를 내리기보다 비워 두는 선택을 함 |
| 원도심 공실은 구조적으로 높다 | 최근 2년 평균 원도심 21.1% vs 그 밖 12.4% | 충장로 같은 원도심은 별도 대책이 필요 |
| 한 번 오른 공실은 오래 간다 | 분기 지속성 0.946, 절반으로 줄기까지 약 3.1년(원도심 약 6.4년) | 기다리는 것만으로는 회복이 느림 |

**AI 예측은 참고 신호로만 씁니다.**
- 4분기 뒤 공실률을 예측하는 모델을 만들었지만, 지금 공실률을 그대로 쓰는 단순 기준보다 오차가 약 0.7%(0.66%)만 작았습니다.
- 공실 악화를 가려내는 정확도(AUC)도 0.58에 그쳤습니다.
- 공실이 오래 이어져서, 현재 공실률이 미래 공실률을 대부분 설명하기 때문입니다.
- 그래서 이 프로젝트는 예측보다 **현상 분석**에 집중합니다. 모델은 공실이 오르는지·내리는지를 보는 **참고 신호**로만 씁니다.

## 5. 제안: 충장로 상생기금 (상생협약)

### 돈의 흐름
1. **세입자**가 계약 월세 100%를 건물주에게 냅니다. 월세는 깎지 않습니다.
2. **건물주**가 월세를 모두 받은 뒤, 건물마다 정한 비율(예시 10%)을 상생기금에 냅니다.
   - 대상은 1차 대상 점포에 새로 들어온 가게의 월세이고, 입점일부터 24개월입니다.
   - 공실 기간에는 내지 않습니다.
3. **지역은행**이 상생기금 계좌를 설정·관리합니다. 출자는 자동이체로 받고, 집행 내역은 분기마다 공개합니다.
4. 매달 또는 분기마다 **예산 규칙**이 항목별 금액을 계산하고, **예산 에이전트(AI)**가 배분 근거와 승인 요청 메모를 씁니다. **상인회**가 승인하면 은행이 집행합니다.
   - 예산 항목은 입점 지원, 공동 홍보, 소비 촉진, 행사, 거리 환경입니다.
   - 들어온 돈의 최소 30%는 적립합니다.
5. 빈 점포가 채워질수록 기금이 커집니다. 보조금이 들어오면 매칭으로 쓰되 일회성 사업에만 배정합니다.

### 금리 유지
- 월세를 내리면 수익으로 매기는 건물값이 내려가고, **LTV(담보 대비 대출 비율)**가 올라갑니다. 그러면 대출 갱신 때 금리가 오를 수 있습니다.
- 상생기금은 계약 월세를 유지하므로 LTV가 높아지지 않습니다. **그만큼 금리를 유지**합니다. 추가 인하는 은행의 선택 조건입니다.
- 예시 건물(5칸 중 2칸 공실, 월세 136만원, 대출 7.5억): 새 가게 월세를 20% 내리면 LTV가 59.7%에서 64.9%로 올라 4년 이자가 약 468만원 늘어난다고 가정했습니다. 상생기금은 LTV 59.7%를 유지합니다.

### 예시 건물 4년 순현금 (입점 연 10% 가정)
| 그냥 비워 둠 | 월세 20% 인하 | 상생협약 참여 |
|---:|---:|---:|
| 5,907만원 | 4,995만원 | 5,744만원 |

- 상생기금은 월세 인하안보다 **+750만원**입니다.
- 그냥 비워 둘 때보다는 −162만원입니다. 은행이 금리를 0.3%p 추가로 내려 주면 +288만원이 됩니다.

### 지역은행이 얻는 것
- **주거래 전환·대환:** 다른 은행 대출을 옮겨 오면 대출 7.5억·마진 2.49% 가정으로 4년 약 7,470만원입니다.
- **건물주 고객·데이터:** 자금력 있는 건물주의 건물·임대·대출 정보로 대환이나 추후 대출을 영업할 수 있습니다.
- **임차인 대출:** 새 가게의 매출 흐름을 상권 데이터로 볼 수 있어 안정적으로 심사할 수 있습니다.
- **그 밖:** 기금·가게 계좌, 담보 위험 감소, 지역재투자 실적과 지역 금융 역할 유지.

## 7. 사용법

### 홈페이지 열기
```powershell
cd 01_홈페이지
python -m http.server 8000 --bind 127.0.0.1
```
- 브라우저에서 http://localhost:8000/index.html 을 엽니다.
- index.html을 직접 더블클릭해도 열립니다. 지도는 Kakao 설정과 인터넷 연결이 필요하며, 불러오지 못하면 위치 안내도를 보여 줍니다.
- 네 HTML과 JS 파일(participation-model, participation-ui, fund-agent, fund-ui)은 같은 폴더에 있어야 합니다.

### 공실 현황
- 지도의 원 크기는 빈자리 수, 색은 비어 있던 기간입니다. 원을 누르면 건물별 상세가 나옵니다.
- 맨 아래 '데이터 분석 결과'에서 근거를 확인합니다.

### 참여 조건 계산
1. 건물 전체 점포 수, 빈 점포 수, 점포 1곳 월세를 넣습니다.
2. 상생기금 출자율(예시 10%)과 약정 기간(24개월)을 정합니다.
3. 결과에서 '상생협약 참여 − 월세 인하안' 금액, 3안 비교, 상생기금 카드, LTV·금리 유지 카드를 봅니다.
4. 필요하면 '은행 추가 금리 인하'를 켜고, 빠른 버튼(출자 15%·5%, 입점 25%, 입점 0%)으로 상황을 바꿔 봅니다.
5. '현재 조건표 저장'으로 결과를 텍스트 파일로 받을 수 있습니다.

### 상생기금·예산
1. 상권 상황 버튼(지금 충장로 / 매출 하락 / 축제 / 공실 개선)을 고릅니다.
2. 상인회가 정하는 값을 넣습니다: 예산 주기, 출자 중인 새 가게 수, 최소 적립 비율, 보조금 매칭(선택).
3. 항목별 예산안, 배분 근거, 상인회 승인 요청 메모, 보조금 없이 4기간 운영한 결과를 봅니다.
4. 'AI 에이전트로 승인 요청 메모 쓰기'를 누르면 AI가 같은 설정으로 예산 규칙을 불러 상인회 승인 요청 메모를 씁니다.
5. '데이터 파이프라인 구축 계획 보기'에서 데이터 수집 → 재학습 → 예산안 → 승인 계획을 봅니다.

## 9. 한계와 확인할 점
- **공실 감소 효과는 아직 검증되지 않았습니다.** 상생기금이 입점을 얼마나 빠르게 하는지는 시범사업(1차 10개 건물)에서 측정합니다.
- **계산 값은 가정입니다.** 출자율, 금리 유지·추가 인하, 은행 마진, 환원율, LTV에 따른 가산금리 폭은 승인되지 않은 제안 조건입니다.
- **공실 지도는 추정입니다.** 등록정보 기반 추정이라 현장 확인 전 참고값입니다.
- **예산 에이전트의 입력 데이터는 예시 값입니다.** 금액은 규칙으로 계산하고 승인 요청 메모는 AI가 실제로 씁니다. 다만 '지금 충장로'의 매출·유동인구·신규 입점 값은 실제 데이터 연동 전 예시이며, 자동 수집·재학습 파이프라인은 구축 계획입니다.
- **AI 참여 상담 에이전트와 예산 에이전트는 실제 작동합니다.** OpenAI API(gpt-5.4-mini, 도구 호출)를 쓰며, 배포 시 Vercel 환경변수 OPENAI_API_KEY가 필요합니다.
- **AI 예측은 참고 신호입니다.** 공실률 예측 성능은 단순 기준과 거의 같은 수준입니다.

## 10. 주요 변경 이력 (2026-11-18, v5)
- **출자 구조:** 세입자는 월세 전액을 내고, 건물주가 받은 월세에서 상생기금에 출자합니다. 첫 2개월 환급은 없앴습니다.
- **기금 운영:** 지역은행 주도로 기금을 설정하고, 예산 에이전트가 매달·분기 예산안을 만들고 상인회가 승인합니다.
- **금리:** 금리 우대 중심에서 'LTV가 유지되는 만큼 금리 유지'로 바꿨습니다.
