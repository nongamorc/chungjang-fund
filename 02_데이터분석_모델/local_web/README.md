# 민간 상생기금 · Python 로컬 웹앱

정부 지원금·공공 매칭 없이, 임대수입 일부와 자발적 민간 기부금으로 운영하는 지역 상생기금입니다. 소비자 페이백·입점 정착금·생존지원은 기금의 지출입니다. 기부금은 별도 수입이며 확보되지 않은 금액의 기본값은 0입니다.

## 실행

Windows PowerShell에서 다음을 실행하세요. Python 3.11 이상을 권장하며 현재 환경의 Python과 scikit-learn 1.8.0으로 검증했습니다.

```powershell
cd C:\Users\user\Documents\RealEstate\충장로_공실펀드\local_web
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

브라우저에서 **http://127.0.0.1:8000** 을 여세요. HTML 파일을 더블클릭하는 방식이 아닙니다. 종료는 실행한 터미널에서 `Ctrl+C`입니다. 설치 이후에는 `run.ps1` 또는 마지막 명령만 실행합니다. 기존 Python에 의존성이 설치되어 있으면 `python app.py`로 실행할 수 있습니다.

8000번 포트를 사용 중이면 `python app.py --port 8002`로 실행하고 해당 포트 주소를 여세요. 초기 패키지 설치와 외부 지도는 인터넷이 필요합니다. 분석·학습·예측·시뮬레이션은 로컬에서 처리합니다. 서버는 `127.0.0.1`에만 연결되며 외부 배포용 서버가 아닙니다.

## 화면 사용 순서

1. **메인**: 문제 상황·조사 경로·전국 유형 비교를 확인합니다. 지도는 위치 안내이며 개별 공실 좌표는 없습니다.
2. **분석**: 데이터 범위, 가설, 고정 4피처와 예측 목표를 확인합니다. 과거 분석은 스냅샷이며 페이지를 열 때 새로 분석하지 않습니다.
3. **모델**: `train 학습·valid 선택` → `선택 고정 후 test 평가` → 상권 선택/입력 → `입력값으로 예측 실행`. 모델은 Python에서 학습합니다.
4. **정책 설계**: 민간 기금의 차별점과 이해관계자의 비용·편익 조건을 확인합니다.
5. **기금**: 출자율·참여율·약정기간·지원 배분을 조정합니다. 확보한 연간 민간 기부금이 있을 때만 입력합니다. 금액은 억원/년이며 운영 중 매년 동일액이 들어오는 가정입니다. 약정 종료 또는 조기 해제 후 유입은 계산하지 않습니다.
6. **결과**: 공실 경로, 기금 규모, 건물주 순현금, 출자율 비교표를 확인합니다. 예측과 정책 효과는 별도이며 자동 연결되지 않습니다.

## 학습과 평가

- 입력: 현재 공실률, 1년 공실 변화, 1년 임대가격지수 변화, 원도심 구분.
- 학습 목표: 4분기 뒤 공실 변화폭. 화면 결과: 현재 공실률 + 예측 변화폭(0~100%).
- train 기준분기 ≤2021Q2 / valid 2022Q3~2023Q2 / test 2024Q3~2025Q2. 목표 기간 겹침 방지 간격 유지.
- OLS·Ridge·Random Forest·Extra Trees·Gradient Boosting을 valid MAE로 선택. 표준화는 train에만 적합.
- test는 선택 후 평가. MAE·RMSE는 %p, R²는 미래 공실률 수준 기준.
- scikit-learn으로 바뀌어 이전 JS의 알고리즘 세부 구현·난수열과 다릅니다. 이전 25.64% 등 수치를 새 결과로 간주하지 마세요. 새 결과는 `validation.json`과 화면에 표시합니다.
- 학습 결과는 서버 메모리에 최대 16회 보관합니다. 서버 재시작 시 다시 학습합니다. 반복 test 열람은 새 독립 검증이 아닙니다.
- 관측 자료는 회고적 자료이며 외부 검증이 아닙니다. 펀드 인과 효과·무손실·담보가치 보전은 증명하지 않습니다.
