06 / 07 · AI 모델 학습

학습 → valid 선택 → test 평가 → 실측값 예측

사전에 고정한 피처
학습 설정

선형회귀 OLS · 릿지 α=10 · Python scikit-learn 사용. 기존 JS 결과와 달라질 수 있습니다. 두 숲은 각 80개 트리/깊이 6/최소 잎 15/노드당 피처 2. RF는 부트스트랩, Extra Trees는 무작위 분할. 아래 조절값은 부스팅에 적용됩니다.

아직 학습하지 않았습니다.

회귀모델 비교 · valid 데이터

목표 = 4분기 후 공실률 − 현재 공실률(%p). 최종 공실률 = 현재값 + 예측 변화폭. 선형회귀를 기준으로 5개 모델을 동일하게 평가합니다. 선택 기준은 valid MAE입니다.

평가 지표는 1년 뒤 공실률의 실제값과 예측값으로 계산한 MAE·RMSE·R²입니다. MAE·RMSE 단위는 %p이며 R²는 단위가 없습니다. 학습은 변화폭으로 하되 평가 전 공실률로 복원합니다. R²가 높다고 급변 예측력이 확보됐다는 뜻은 아닙니다.

학습 버튼을 누르면 선형회귀·릿지·랜덤포레스트·Extra Trees·부스팅을 같은 조건으로 비교합니다.

test 실제 vs 예측 (%)

선택 고정 후 test 버튼으로 평가합니다.

valid 피처 중요도 (선택 후 설명용)

학습 후 표시됩니다.

실측값 입력 · 4분기 후 예측

공실 변화 = 현재 − 전년 동분기 공실률. 지수 변화 = (현재 지수 / 전년 동분기 지수 − 1) × 100. 금액·증감률과 %p를 혼동하지 마세요.

2027년 2분기 공실률–학습 후 표시됩니다.

예측 실행 후 결과의 의미를 설명합니다.

모델별 수치와 비교 기준 확인

선형회귀를 기준으로 동일한 피처·분할에서 5개 회귀모델을 비교합니다. valid 변화폭 MAE로 선택하고 test는 선택 이후 평가에만 사용합니다.
