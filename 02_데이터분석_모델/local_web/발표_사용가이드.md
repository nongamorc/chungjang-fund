# 공실을 줄이는 민간 상생기금 — 발표·사용 가이드

## 제안의 목적

정부에서 지원금을 받는 방식이 아니라, 지역의 임대수입 일부를 모아 상권에 재투자하는 민간 상생기금이다. 실제 임대료를 받을 때만 출자하고, 자발적 민간 기부금을 별도로 받을 수 있다. 소비자 페이백은 기부나 수익이 아니라 소비를 지원하는 지출이다. 이 기금은 원금·배당을 약속하는 투자상품으로 설명하지 않는다.

## 1페이지: 왜 공동 개입을 검토하는가

- 기존 R-ONE 분석에서 금남로/충장로 공실률은 2013년 15.2%에서 2026Q2 26.5%로 상승했다. 같은 시점 상권별 중앙값은 광주 12.3%(13개), 전국 13.0%(283개)로, 금남로/충장로가 각각 14.2%p·13.5%p 높다. 두 집단 모두 동일한 방식으로 산출했으며 면적 가중 지역 통계가 아니다. 동일 표본의 단순평균(광주 15.0%, 전국 14.3%)을 사용해도 높은 공실이라는 결론은 같다.
- 기존 분석에서 공실이 1년간 3%p 이상 오른 관측 중 66.8%는 임대가격지수가 1% 이상 하락하지 않았다. 이는 관측된 조정 패턴이며 대출 압박이 원인이라는 입증은 아니다.
- 높은 공실과 조정 지연은 공동 대응의 검토 근거다. 자연 회복 불가능이나 특정 펀드의 성공을 입증하지 않는다.
- [광주일보 보도](https://v.daum.net/v/20260127231634822)의 충장로1가 입구 → 충장우체국 → 충장파출소 450m 조사에서는 199호실 중 공실 64곳(32.2%)이었다. 지도는 위치 안내이며 호실 좌표와 조사 경계를 갖고 있지 않다. 호실 수 통계를 R-ONE 면적 기준 공실률에 혼합하지 않는다.

## 2페이지: 분석과 AI의 역할

| 피처 | 정의 | 단위 |
|---|---|---|
| 현재 공실률 | 기준분기 중대형상가 공실률 | % |
| 1년 공실 변화 | 현재 − 전년 동분기 | %p |
| 1년 임대가격지수 변화 | (현재 / 전년 동분기 − 1) × 100 | % |
| 원도심 여부 | 프로젝트 지정 1 / 기타 0 | 이진값 |

학습 목표는 4분기 뒤 공실 변화폭이다. 예측 변화폭을 현재 공실률에 더해 사용자에게 1년 뒤 공실률을 보여준다. 기금 출자율·지원금은 피처에 없으므로 AI가 펀드 효과를 학습한 것이 아니다.

Python에서 train 2,806건으로 학습하고 valid 920건의 MAE로 선택한 뒤, 고정된 모델을 test 956건으로 평가한다. train 기준분기는 2021Q2까지, valid는 2022Q3~2023Q2, test는 2024Q3~2025Q2이다. 4분기 뒤 목표가 다음 분할에 겹치지 않도록 간격을 둔다. 과거에 열람한 자료의 회고적 평가이며 새로운 외부 검증은 아니다.

## 3페이지: Python 모델 결과

이번 scikit-learn 기본 설정에서 valid로 선택된 모델은 Extra Trees다. 이는 무작위 후보 분할로 여러 회귀나무를 만든 뒤 평균하는 모델이다. 나무를 무작위로 만드는 것과 정답을 무작위로 출력하는 것은 다르다. 자세한 설명은 services/prediction.py의 주석을 참고한다.

| 모델 | test MAE (%p) | test RMSE (%p) | test R² |
|---|---:|---:|---:|
| 선형회귀 | 2.978 | 3.883 | 0.760 |
| 릿지 | 2.975 | 3.880 | 0.760 |
| 랜덤포레스트 | 2.915 | 3.843 | 0.765 |
| Extra Trees | 2.750 | 3.665 | 0.786 |
| 부스팅 | 3.000 | 3.977 | 0.748 |

충장로 기본 입력 26.50%, 1년 변화 +1.20%p, 임대가격지수 약 −1.02%, 원도심 1에서 2027Q2 예측은 **26.05%**, 현재 대비 약 **−0.45%p**다. 감소폭보다 test 평균 오차가 크므로 감소를 확정적으로 주장하지 않는다. R²는 미래 공실률 수준의 지표이며 방향이나 급변 예측의 정확도가 아니다. 이전 자체 JS 구현의 25.64%와 혼용하지 않는다.

## 정책 설계를 먼저 설명한다

| 기존 접근과의 비교 | 제안의 차이 | 확인할 조건 |
|---|---|---|
| 공공 지원 중심 | 민간 임대수입·자발적 기부금으로 조성 | 실제 수납과 민간 약정 지속성 |
| 개별 임대료 인하 | 임대수입 일부를 공동으로 집행 | 출자 후 순현금·담보평가 영향 |
| 일회성 행사 | 기간을 정한 입점·소비·영업 유지 지원 | 추가 입점·순증 소비·지원 종료 후 유지율 |

건물주: 수입이 있을 때만 출자하되, 출자액은 비용이다. 공실 감소에 따른 추가 순수입과 비교해야 한다.

세입자: 정착금·생존지원과 소비 유입을 기대하되 지원 종료 후의 임대료 부담과 영업 유지가 중요하다.

소비자: 참여 상권 소비에 대한 페이백을 받을 수 있다. 기존 소비가 단순 이동하는 것과 추가 소비를 구분한다.

정부: 사업 재원을 요청하지 않는다. 그렇다고 사회 전체의 행정·감독 비용까지 없다고 주장하지 않는다.

‘누구도 손해 보지 않는다’는 보장 대신, **지역의 자생적 재원을 조성하고 참여자의 비용·편익이 균형을 이루는 조건을 찾는다**고 설명한다. Camden·Kent는 공공 재원이 포함되어 이번 민간 재원 설계의 근거에서 제외했다. 이전 사례 상세는 수정 전 백업에 보관한다.

## 시뮬레이터의 재원과 지출

연간 기금 = 참여 면적 × 임대료 × 12 × 참여 건물 임대 중 비율 × 출자율 × 출자율 인하계수 + 확보한 민간 기부금.

정부 지원금과 공공 매칭은 옵션과 계산식 모두 없다. 기부금 기본값은 0억원이며 입력한 금액이 운영 중 매년 동일하게 들어온다고 가정한다. 조기 해제·약정 종료 이후에는 신규 기금 유입을 중단한다. 페이백·정착금·생존지원·행사 비중을 조절하며 실비 5%를 포함해 전액 배분한다.

조작판에서 출자율·참여율·기부금·지원 배분을 바꾸고 공실 경로, 기금 규모, 건물주 순현금을 비교한다. 반응 계수는 정책 가정이며 효과가 검증된 값이 아니다. AI 입력 예측과 자동 연결하지 않는다. 3,000회 민감도 그래프는 기존 기본 가정의 저장 결과로, 현재 조작판을 바꿀 때 새로 계산되는 그래프가 아니다.

## 결론과 전국 서비스 범위

> 충장로의 공실 문제를 출발점으로, 지역의 수입이 지역에 돌아오는 민간 상생기금을 제안합니다. 전국 주요 상권의 전망과 기금 운영 조건을 비교하는 서비스로 확장하고자 합니다. 현재 283개 상권 입력 예측은 가능하며, 전국 기금 시뮬레이션에는 지역별 건물 수·면적·임대료와 시범사업 반응 계수를 추가 연결해야 합니다.

현재 기금 조작판의 612동 등은 충장로 가정이다. 다른 상권을 AI 입력에서 선택해도 자동 교체되지 않는다. 데이터로 개입 필요성을 검토하고, 예측으로 전망을 참고하며, 가정 기반 시뮬레이션으로 실행 조건을 비교하는 서비스다.

실행법·파일 구조·검증 명령은 [local_web 사용법](README.md)을 참고한다.
